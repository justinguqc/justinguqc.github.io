Design Evolution

A clearer way to start. Both participants needed help finding AITrace or knowing where to click. We plan to add a labelled Explain change action beside the changed code, so users can open an explanation without having to guess what an icon does.

Pop-up explanations linked to the code. Both participants preferred the pop-up window. However, P2 sometimes referred to the explanation panel when asked to identify changed code. We plan to keep explanations beside the code and highlight the matching lines when a pop-up opens. A short explanation will appear first, with more detail available when needed.

A complete view of changes. P2 found the plus/minus markers helpful and worried about seeing all changes in longer code replacements. We plan to keep added and deleted code visible, with previous/next actions and a review count. This should help users check the full change and keep track of their progress.
