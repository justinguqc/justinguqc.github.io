Testing procedure

Each participant completed Group B’s three documented usability tasks: claim assessment, selective copying, and correction/reporting. Participants were asked to think aloud while completing the tasks. We recorded time on task, task success, task-specific measures, errors, and critical incidents.

3. Test Plan Critique

Strengths and limitations

  • The three tasks cover checking evidence, copying with context and challenging a label. The briefing, examiner roles and run log give the testing team a useful starting point.
  • The plan also needs a clear timeout rule. Direct With evidence copying can succeed without a warning. Reporting is simulated and submits when a reason is selected, without a separate Submit button.

B's submitted files did not include a consent form or the ten-item SUS questionnaire mentioned in the test plan. These should be included so another team can run the study without having to create missing materials.

Nielsen heuristic analysis

The source review focuses on clear feedback, error prevention, user control and keyboard recovery. Findings below are provisional; they still need browser checks and B's three independent evaluators. The sleep claim's misleading green label is a planned trap, not an accidental defect.

Changes or additions made

We kept all three tasks and used two participant records, with independent and assisted completion recorded separately. Warning exposure was treated as not needed for a direct With evidence copy. Source access and evidence interpretation were recorded separately, with participant counts reported out of two.

4. Design Critique

High-priority improvements

Check copy protection with labels off and the loss of draft text on Reset. If confirmed in the browser, keep warnings active and add confirmation or Undo before clearing work. These priorities remain provisional until testing.

Medium-priority improvements

Clarify that report submission is simulated, and fix keyboard focus after cancelling a report. Both changes would make it clearer what happened and how to continue.

Low-priority improvements

Update the guide's filename and replace its screenshot placeholder. Keep the current label symbols and copy previews; broader layout changes should follow the user sessions.
