Testing procedure

Both participants worked through Group B’s three usability tasks in order. The tasks covered claim assessment, copying with evidence, and label reporting. Participants explored the Study tips screen first and were asked to think aloud during the tasks. The run logs record time, completion, errors and help from the facilitator.

Additional exercises

The sessions ended after Task 3. The toggle, keyboard and reset checks came from source inspection.

Cross-participant comparison

Both participants reached the sleep source. P1 gave a direct yes, while P2 described the support as indirect. They took different copying routes: P1 assembled the claim and sources over several pastes, while P2 pasted only the summary. Both reported the Pomodoro label, with P2 using browser Find to reach the link.

Analysis

Only P1 answered within 45 seconds. Neither participant identified the evidence gap, yielding a detection rate of 0/2 against B’s below-50% reference. Neither copy attempt showed a warning, so the sessions yielded no warning responses to score.

3. Test Plan Critique

Strengths and limitations

  • The three tasks cover checking evidence, copying with context and challenging a label. The briefing, examiner roles and run log give the testing team a useful starting point.
  • The plan needs a clear timeout rule and a definition of a successful evidence copy. Check the pasted draft for the claim, evidence and label separately. Record warning exposure separately because users can reach the draft without seeing a warning.

B’s submission omitted the consent form and the ten-item SUS questionnaire listed in the test plan. Include both in the testing package so another team can follow the same procedure.

4. Design Critique

High-priority improvements

Show the scope of the evidence next to the claim. The sleep source discusses memory and gives no grade result. Place a prominent Copy claim with evidence button beside the claim and keep the preview that shows the claim, label and sources together.

Medium-priority improvements

Add a direct link to Assignment draft in the copy confirmation. Move the report link nearer the claim heading and keep the confirmation that both participants reached.

Low-priority improvements

Update the guide's filename and replace its screenshot placeholder with a view that points out the copy, draft and report controls.
